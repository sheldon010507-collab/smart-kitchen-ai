# 實拍素材目錄

請將已拍好的視頻放到此目錄，並按下列文件名放置，以便 Remotion 自動加載：

| 文件名 | 對應段落 | 時長建議 |
|--------|----------|----------|
| `01-hook.mp4` | 開場：直擊痛點（手寫單、計算器、過期食材、廚房亂象） | ~15 秒 |
| `02-smart-setup.mp4` | 智能初始化（Setup Wizard、Modern Cafe、一鍵填滿） | ~20 秒 |
| `03-visual-inventory.mp4` | 視覺庫存（手機掃冰箱、AI 識別、半瓶牛奶） | ~30 秒 |
| `04-auto-purchase.mp4` | 自動採購（Auto Generate、低庫存/臨期、一鍵訂單） | ~30 秒 |
| `05-ecosystem.mp4` | 生態系統（Costing、Staff、Menu AI、Thinking Chef 快剪） | ~55 秒 |
| `06-conclusion.mp4` | 結尾（Dashboard 全景、多端同步、Logo） | ~30 秒 |

支持格式：MP4（H.264）、WebM、MOV 等 Remotion 支持的格式。  
若使用其他文件名或路徑，可在 Studio 中對應 Composition 的 defaultProps 裡修改 `src`。
